## نظرة سريعة على كل وحدة

- **تسجيل الدخول (Authentication):** دخول باسم المستخدم وكلمة المرور مع حماية
  من التخمين (5 محاولات) وفرض الخروج للحسابات المعطّلة.

- **لوحة المعلومات (Dashboard):** أرقام حيّة عن الأسطول (المركبات، التكاليف،
  التنبيهات القريبة) مع رسمين وجدولي ترتيب.

- **الإشعارات والتنبيهات (Notifications):** جرس للإشعارات + تنبيهات مجدولة
  يوميًا (زيوت/فلاتر/تأمين/رخص/مركبات متوقفة/صيانة متأخرة/مخزون منخفض) تُرسل
  لمن يملك الصلاحية.

- **الإعدادات والتفضيلات:** إعدادات عامة للتطبيق (اسم/شعار) + تفضيلات شخصية
  (حجم الخط). الثيم يخزن في كوكي وليس في قاعدة البيانات.

- **المستخدمون والأدوار (Users & Roles):** إدارة الحسابات (دور واحد لكل مستخدم)
  وإدارة الأدوار والصلاحيات عبر Spatie. أدوار مسبقة: Admin (كل الصلاحيات)
  و Viewer (القراءة فقط).

- **الإدارات والأقسام:** الهيكل التنظيمي للأسطول (الإدارة ← الأقسام ← السائقون)،
  المركبة ترتبط بالإدارة مباشرة.

- **السائقون (Drivers):** بيانات السائقين والرخص + العلاقة بالمركبات عبر الإسناد
  + صفحة عرض بتبويبات (مخالفات/حوادث/المركبة الحالية).

- **المركبات (Vehicles):** الوحدة الأوسع: بيانات المركبة وحالتها وعدادها ووقودها
  وزيوتها وفلاترها وتأمينها وحوادثها ومصروفاتها وإسناد السائقين.

- **قراءات العداد (Odometer):** تسجيل القراءات + التصحيحات (بسبب). المكان الوحيد
  لتعديل `current_odometer` هو `OdometerService`.

- **كتالوج الزيوت والفلاتر:** أنواع الزيوت والفلاتر بأعمارها الافتراضية
  بالكيلومترات.

- **الوقود (Fuel Logs):** تسجيل التعبئة مع سلسلة عداد مستقلة وحساب الإجمالي
  ومعدل الاستهلاك.

- **تغيير الزيت والفلتر:** تسجيل التغييرات مع حساب وتخزين قراءة التغيير التالي
  وحساب المتبقي/المتأخر ديناميكيًا.

- **التأمينات (Insurance Policies):** بوليصات لكل مركبة، واحدة حاليّة فقط، مع
  تجديد تلقائي عبر `renew()`.

- **المخالفات (Driver Violations):** مخالفات السائقين مع توليد مصروف تلقائي عند
  وجود مركبة ومبلغ.

- **الحوادث (Incidents):** الحوادث بصورها وحالة المطالبة التأمينية وربط البوليصة.

- **المصروفات (Expenses):** سجل مركزي؛ المصروفات إما تلقائية (من الوقود/الزيوت/
  الفلاتر/الصيانة/المخالفات) أو يدوية (قطع غيار/أخرى).

- **أوامر الصيانة (Maintenance):** سجل أعمال الصيانة لكل مركبة (السبب، الورشة،
  التكاليف، الحالة…). الفواتير تُنشأ من داخل أمر الصيانة، ويُوازن حالة المركبة
  تلقائيًا مع حالة الصيانة.

- **فواتير الصرف (Invoices):** الطريقة الوحيدة لصرف قطع الغيار من المخزن
  لأمر صيانة معيّن. كل فاتورة تخص أمر صيانة واحد، وعند إنشائها تُخصم الكميات
  تلقائيًا من المخزون.

- **قطع الغيار (Spare Parts):** سجل للقطع + تتبّع المخزون (شراء / جرد / صرف).
  المخزون محسوب تلقائيًا من مجموع الحركات، وليس عمودًا محفوظًا في قاعدة البيانات.

- **الموردين (Suppliers):** سجل الموردين + فواتيرهم (كم علينا) + مدفوعاتهم
  (كم دفعنا) + الرصيد المتبقي، كلها محسوبة تلقائيًا. فواتير المورد يمكن أن
  تحمل بنود قطع غيار تُشترى تلقائيًا (تزيد المخزون).

- **التقارير (Reports):** مركز تقارير للقراءة فقط — نموذج فلترة → نتائج →
  طباعة/PDF، لعشر تقارير (وقود، أسطول، زيوت/فلاتر، تأمين، حوادث، مصروفات،
  مخالفات، صيانة، موردون، قطع غيار).
